# VTU GPTrack

A simple web-based SGPA and CGPA calculator designed for VTU students.

## 🌐 Live Demo

[Visit VTU GPTrack](https://inisah-web.github.io/VTU-GPTrack/)

## ✨ Features

- VTU P24 SGPA Calculator
- VTU CGPA Calculator
- Automatic grade point calculation
- Clean and modern student-friendly interface
- Feedback form for user suggestions

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🎯Purpose

VTU GPTrack was created to make SGPA and CGPA calculations simpler and more convenient for VTU students.
Specified as P24 scheme. May vary for other schemes and branches.
